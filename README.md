# Spatial Transcriptomics Bioinformatics Analysis

This repository contains custom code and analysis workflows for the bioinformatic analysis of spatial transcriptomic datasets. The repository includes Python notebooks for data preprocessing and downstream analyses, reusable helper modules, and R scripts for figure generation.

## Repository structure

```text
.
├── code/               # Python notebooks for analysis and R files for visualization
├── helpers/             # Helper functions and reusable Python modules      
└── README.md
```

## Analyses

The analysis workflows include, but are not limited to:

* Data preprocessing and quality control
* Data integration and normalization
* Cell clustering and annotation
* Differential expression analysis
* Spatial analyses
* Statistical analyses
* Figure generation

## Data

The datasets used in this study are not included in this repository. Users should obtain the relevant datasets from the public repositories listed in the associated publication and place them in the appropriate local directories before running the analysis.

## Requirements

The analyses were performed using Python and R. Required packages and software versions are described in the accompanying manuscript and environment files.
